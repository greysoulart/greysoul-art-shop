Greysoul Art live schalten

Kurze Anleitung, damit Claudia Produkte & Blogbeiträge später selbst über ein einfaches Formular pflegen kann – ganz ohne Programmieren.

1. GitHub-Konto (kostenlos)

für Claudia
  1. Auf github.com/signup ein kostenloses Konto anlegen.
  2. Ein neues privates Repository erstellen, z. B. mit dem Namen greysoul-art-shop.
  3. Unter Settings → Collaborators die Person hinzufügen, die den Code hochlädt (GitHub-Benutzername von der Person, die diese Anleitung für dich vorbereitet hat).

2. Code hochladen

technischer Schritt – macht die Person, die den Shop gebaut hat
Sobald der Zugriff auf das Repository da ist, wird der fertige Shop-Ordner einmalig dorthin hochgeladen (per git push). Das ist ein einmaliger technischer Schritt, danach nie wieder nötig.

3. Netlify-Konto (kostenlos)

für Claudia
  1. Auf netlify.com registrieren – am einfachsten mit „Sign up with GitHub“, dann sind beide Konten direkt verbunden.
  2. „Add new site“ → „Import an existing project“ auswählen und das GitHub-Repository verbinden.
  3. Beim Einrichten: Build command leer lassen, Publish directory: . (ein Punkt). Dann „Deploy“ klicken.
  4. Nach ein paar Sekunden ist die Seite live, z. B. unter irgendein-name.netlify.app.

4. Login für den Admin-Bereich einrichten

für Claudia, einmalig
  1. Im Netlify-Dashboard der Seite: Site configuration → Identity → Enable Identity.
  2. Bei „Registration preferences“ „Invite only“ auswählen (damit sich niemand Fremdes anmelden kann).
  3. Identity → Services → Git Gateway → Enable Git Gateway.
  4. Identity → Invite users → die eigene E-Mail-Adresse eintragen und einladen.
  5. Die Einladungsmail öffnen, eigenes Passwort setzen – fertig.

5. Produkte & Blogbeiträge pflegen

ab jetzt jederzeit selbstständig für Claudia
  1. https://irgendein-name.netlify.app/admin/ öffnen (Adresse aus Schritt 3, mit /admin/ am Ende).
  2. Mit dem in Schritt 4 gesetzten Passwort einloggen.
  3. Links „Produkte“ oder „Blog“ auswählen, „+ Neu“ klicken, Formular ausfüllen (Titel, Bild hochladen, Preis, Text …), „Publish“ klicken.
  4. Nach wenigen Sekunden ist die Änderung live auf der echten Seite sichtbar.
Eigene Wunsch-Domain (z. B. greysoul-art.de) ist optional und separat bei einem Registrar zu kaufen (ca. 10–15 €/Jahr), dann in den Netlify-Domaineinstellungen hinterlegen. Ohne eigene Domain bleibt die netlify.app-Adresse kostenlos bestehen.
Noch offen vor dem richtigen Live-Start: echte Zahlungsanbindung (aktuell nur Demo) sowie die echten Angaben für Impressum und Datenschutz.
