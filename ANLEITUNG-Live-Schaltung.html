1. GitHub-Konto & Repository

✓ erledigt
Konto greysoulart angelegt, Repository greysoul-art-shop erstellt.

2. Code hochladen

✓ erledigt
Der komplette Shop-Code liegt jetzt bei github.com/greysoulart/greysoul-art-shop.

3. Netlify mit dem Repository verbinden

für Claudia
  1. Auf app.netlify.com einloggen – unbedingt mit „Log in with GitHub“ und dabei das greysoulart-Konto wählen (wichtig: nicht irgendein anderes Konto, sonst verbindet sich Netlify mit dem falschen Repo).
  2. „Import an existing project“ → GitHub auswählen.
  3. Falls gefragt wird, auf welchem Konto die Netlify-App installiert werden soll: greysoulart wählen, „All repositories“ oder „Only select repositories“ → greysoul-art-shop auswählen → Install.
  4. Das Repository greysoul-art-shop aus der Liste auswählen.
  5. Build command: leer lassen. Publish directory: . (ein einzelner Punkt).
  6. Deploy klicken. Nach ca. einer Minute ist die Seite live, z. B. unter irgendein-name.netlify.app – den Namen kannst du später in den Projekteinstellungen ändern.

4. Login für den Admin-Bereich einrichten

für Claudia, einmalig
Hinweis: Der ursprünglich einfachere Weg („Identity“ mit E-Mail/Passwort) funktioniert bei neuen Netlify-Projekten nicht mehr (der dafür nötige Baustein „Git Gateway“ wurde eingestellt). Stattdessen loggt sich Claudia künftig mit ihrem GitHub-Konto (greysoulart) in den Admin-Bereich ein – braucht sie ja ohnehin schon.
A) Bei GitHub eine „OAuth App“ anlegen
  1. Eingeloggt als greysoulart zu github.com/settings/developers gehen.
  2. „OAuth Apps“ → „New OAuth App“ (bzw. „Register a new application“).
  3. Application name: z. B. Greysoul Art CMS
  4. Homepage URL: die Netlify-Adresse aus Schritt 3 (z. B. https://irgendein-name.netlify.app)
  5. Authorization callback URL: genau https://api.netlify.com/auth/done eintragen (exakt so, sehr wichtig!)
  6. „Register application“ klicken.
  7. Auf der neuen Seite die Client ID notieren.
  8. „Generate a new client secret“ klicken, den angezeigten Wert sofort kopieren und sicher merken – er wird danach nicht mehr angezeigt.
B) Client ID & Secret bei Netlify eintragen
  1. Im Netlify-Projekt: Project configuration → Security → OAuth.
  2. Unter „Authentication Providers“ → „Install provider“.
  3. GitHub auswählen, Client ID und Client Secret aus Schritt A einfügen, speichern.

5. Produkte & Blogbeiträge pflegen

ab jetzt jederzeit selbstständig für Claudia
  1. https://irgendein-name.netlify.app/admin/ öffnen (die Adresse aus Schritt 3, mit /admin/ am Ende).
  2. „Login with GitHub“ klicken, mit greysoulart einloggen/bestätigen.
  3. Links „Produkte“ oder „Blog“ auswählen, „+ Neu“ klicken, Formular ausfüllen (Titel, Bild hochladen, Preis, Text …), „Publish“ klicken.
  4. Nach wenigen Sekunden ist die Änderung live auf der echten Seite sichtbar.
Eigene Wunsch-Domain (z. B. greysoul-art.de) ist optional und separat bei einem Registrar zu kaufen (ca. 10–15 €/Jahr), dann in den Netlify-Domaineinstellungen hinterlegen. Ohne eigene Domain bleibt die netlify.app-Adresse kostenlos bestehen.
Noch offen vor dem richtigen Live-Start: echte Zahlungsanbindung (aktuell nur Demo) sowie die echten Angaben für Impressum und Datenschutz.
